#  The DAILY-Newspaper

A newspaper-style website built using **HTML5 and CSS3** that presents news articles in a structured, multi-section newspaper layout. The website features a prominent headline, technology news, national updates, financial news, and sports coverage.

##  About the Project

The DAILY-Newspaper is a front-end web development project designed to recreate the look and feel of a traditional newspaper using modern web technologies.

It uses CSS Grid and Flexbox to organize news articles into multiple sections, combining text and images to create a clean, editorial-style layout.

## ✨ Features

- **Featured News:** A prominent headline with an image and article summary.
- **Multi-Column Layout:** Different grid layouts for organizing news articles.
- **Image Integration:** Visual elements to make the newspaper more engaging.
- **Structured Design:** Clearly separated news sections with headings, borders, and spacing.

## 🛠️ Technologies Used

- **HTML5** — Structure and content of the newspaper.
- **CSS3** — Styling, CSS Grid, Flexbox, spacing, and layout design.

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Open the project folder:

   ```bash
   cd The-DAILY-Newspaper
   ```

3. Open `p7.html` in your web browser.

   You can also open the folder in VS Code and use the Live Server extension.
